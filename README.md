# Quitasol – Joyas de plata 925

A single static page for the Quitasol jewelry brand. It holds the Open Graph tags that make a link preview appear when the site is shared on WhatsApp, and it sends visitors straight to the Quitasol catalog hosted as a Claude artifact.

- Tech: plain HTML with no build step, hosted on Netlify (`netlify.toml` publishes the repo root).
- Run locally: open `index.html` in a browser, or run `netlify dev`.
